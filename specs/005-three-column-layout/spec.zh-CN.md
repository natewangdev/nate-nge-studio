## 用户场景与测试 *(必填)*

### 用户故事 1 - 在三栏外壳中工作（优先级：P1）

操作者打开 NGE-STUDIO，看到并排三区：左为游戏/脚本目录，中为启动参数（表单下为启动/暂停/结束与状态），右为实时日志。默认宽度比 2:3:3。可拖动分割条；重启后从本机设置恢复宽度。

**优先级理由**：把监控与配置分开是本功能的核心交付。

**独立测试**：典型桌面分辨率启动；确认三栏与控件位置；拖动分割条后重启验证恢复；跑样例脚本确认日志只在右栏出现。

**验收场景**：

1. **给定**以常规桌面尺寸打开 NGE-STUDIO，**当**操作者查看主窗口，**则**看到三块横向区域：左目录、中启动参数、右实时日志（而非今日参数与日志同列纵向堆叠）。
2. **给定**主窗口可见，**当**操作者查看中间栏，**则**启动/暂停/结束与运行状态在启动参数表单**下方**（不是窗口通栏底栏，也不是右栏日志上方）。
3. **给定**首次启动且无已存布局（或布局设置已清空），**当**主分割条初始化，**则**三栏默认 stretch/宽度比为 **2 : 3 : 3**（左 : 中 : 右）。
4. **给定**操作者拖动分割条后退出，**当**在同一机器/用户设置存储下再次打开，**则**分割尺寸与上次保存一致（允许控件取整误差）。
5. **给定**脚本运行并打日志，**当**操作者观看 UI，**则**实时日志出现在**右栏**，左/中栏仍可操作（保留规则同 001 FR-013）。
6. **给定**已保存的分割尺寸损坏或不完整，**当**加载设置，**则**回退默认 2:3:3 且不崩溃。

---

### 边界情况

- 窗口很窄：仍保持三栏；栏内可滚动；**不得**退回旧的参数+日志同列堆叠。
- 未选脚本：布局不变；空状态遵循 001。
- 多显示器 / DPI：恢复后仍可用；过小则钳制最小宽度，仍保持三栏。
- 品牌标题：可留在左栏目录上方；**不得**把日志挤回参数下方。

## 需求 *(必填)*

### 功能需求

- **FR-001**：主工作区**必须**为**三栏**横向布局：左=游戏/脚本目录；中=启动参数；右=实时日志。
- **FR-002**：启动、暂停、结束与运行状态**必须**出现在**中间栏**、启动参数表单下方。
- **FR-003**：无持久化布局时，默认宽度比**必须**为左 : 中 : 右 = **2 : 3 : 3**。
- **FR-004**：栏边界在会话内**必须**可拖拽调整。
- **FR-005**：调整后的分割尺寸**必须**写入既有本机设置，并在同机同用户下次启动时恢复。
- **FR-006**：无效/缺失的布局数据**必须**回退 2:3:3，且不得导致启动失败。
- **FR-007**：实时日志行为（近实时、保留至下次启动）**必须**符合 001 FR-013；本功能仅改变放置位置到右栏。
- **FR-008**：目录选择与启动参数编辑语义**必须**保持 001；本功能只改布局。

### 关键实体

- **MainLayout**：三栏外壳（目录 | 参数+控件 | 实时日志），默认比 2:3:3。
- **LayoutSettings**：设置文档中持久化的分割尺寸（或等价 stretch）。

## 成功标准 *(必填)*

### 可衡量结果

- **SC-001**：首次在 ≥1280×720 打开时，观察者可在 3 秒内辨认出三栏（目录 / 参数 / 日志），无需读文档。
- **SC-002**：调整宽度并重启一次后，恢复宽度与上次会话偏差不超过 UI 取整容差（除非设置被清空或非法）。
- **SC-003**：样例脚本 ≥1 行/秒打日志时，右栏感知延迟仍满足 001 SC-004（典型开发机 <1s）。
- **SC-004**：中间栏启停控件无需把日志面板滚走即可触及（控件不再被同列高大日志堆压住）。

## 假设

- 品牌文案可留在左栏目录上方；细部装饰为实现细节。
- 具体像素由 2:3:3 与窗口尺寸推导；stretch 或保存像素均可，只要首次布局符合比例。
- 设置 schema 增加布局字段；旧文件无该字段时用默认（向后兼容）。
- 快捷键编辑 UI 位置不变；本功能不重做设置对话框。
- 非 Windows / 移动布局不在范围。
